# runbooks 收录标准

> 只放**可重复执行的操作知识**：照着做能得到预期结果，且步骤会随环境变化而需要维护。

收录：

- 部署与进程启停、配置项口径、停机与升级
- 故障定位：按现象组织，给出「先看什么、怎么处置」
- 数据搬运：内网取数、本地复现、备份与恢复
- 跑批与实验的操作流程（怎么跑、产物在哪、跑完核什么）

不收录（按归属转出）：

| 内容 | 归属 |
|---|---|
| 与实验批次绑定的操作（AB 两臂对照） | `experiments/docs/`（`experiments/*` 被忽略，仅该子目录放行） |
| 缺陷分析与改进清单，已收口 | `../history/` |
| 某次改动的实施记录、验证清单 | `../history/` |
| 长期契约与设计口径 | `../design/` |
| 不易从代码看出的决策与取舍 | `../adr/` |
| 尚未解决的问题 | `../遗留问题清单.md` |

写新 runbook 前先看 `../README.md`；同类内容已有文档时改那一份，不要新开。
