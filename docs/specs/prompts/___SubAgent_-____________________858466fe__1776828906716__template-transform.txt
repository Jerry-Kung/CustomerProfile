证据线索JSON数据文件格式：
{
    "evidence_items": [
        {
		    "evidence_id": "ev_001", // 证据ID，编号从001开始顺延
            "evidence_category": "证据线索分类",
            "evidence_description": "证据线索内容描述",
            "raw_support": "参考的原始输入信息",
            "evidence_level_suggestion": "A | B | C | D | E",
            "extraction_confidence": 0.9 // 抽取置信度，0-1之间
        },
        ...
    ]
}
其中，evidence_level_suggestion为当前证据线索的分级，A级证据的可靠性/证明力度最强，E级最弱，详细如下：
- A级：直接事实证据，强特征，几乎可以明确确认的信息。
- B级：行为模式证据，在客户的信息包中反复多次出现，可以进行归纳的稳定主题或场景。
- C级：稳定的自我呈现证据，从客户的社媒、沟通信息中能够识别出的，较为明显的客户个人特征信号，强度中等。
- D级：弱参考信号，无法独立支持有效的推断结论（孤证不立），仅能提供弱参考。
- E级：缺失信息，只标记未知，一般不参与正向推断。
