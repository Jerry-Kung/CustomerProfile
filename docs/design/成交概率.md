# 成交概率 LLM 节点配置说明

## 1. 背景与定位

销售人员希望把「客户购车意向等级」量化为一个「成交概率」数值：等级越高，概率越高；
同一等级内部，再依据客户展现出的实际意向强度做轻微调整。

## 2. 节点契约

### 2.1 输入

单条 user message，由四段纯文本拼成：

| 区块 | 来源 | 渲染方式 |
|---|---|---|
| 购车意向等级 | `analysis_result.ai_insight.purchase_intent_level.value` | 原值（H / A / B / C / 待识别） |
| Notes | `analysis_result.basic_notes_updates` | 逐行「中文字段名：中文取值」，用仓库现有渲染（`src/customer_profile/readable.py` 的 `readable_facts`），不直接 dump 英文键 |
| 画像卡 | `ai_insight.customer_segment` / `purchase_decisions` / `deal_battle` / `decision_psychology` | 各区块的 label 与 summary（推理细节可省略） |
| 跟进履历 | `analysis_result.follow_up_history` | 时间、跟进节点、渠道/结果/销售意向级别/下一步，加跟进内容 |

### 2.2 输出

```json
{"成交概率": 12, "微调依据": "计划3个月以上、多店对比未试驾、防备拖延，处区间偏低"}
```

「成交概率」是唯一交付物（整数）；「微调依据」只用于人工核对，下游不需要消费。

### 2.3 档位区间与取整口径

取整数，为避免端点重叠，上界归高档：

| 等级 | 含义 | 成交概率区间 |
|---|---|---|
| H | 预计 7 天内可成交 | 60~100 |
| A | 预计 14 天内可成交 | 40~59 |
| B | 预计 30 天内有成交机会 | 20~39 |
| C | 预计 30 天内难以成交 | 1~19 |
| 待识别（未定级） | 信息不足，暂不判断 | 1~19 |

## 3. 提示词（定稿）

按单条 user message 使用，`{level}` / `{notes}` / `{profile_card}` / `{follow_up}` 为占位符：

```text
你是汽车销售团队的成交预测助手。下面是一份已经完成的客户画像分析结果，请据此判断该客户在未来 30 天内完成购车成交的可能性，输出一个「成交概率」数值（0~100 的整数）。

# 输入说明

依次给出四部分材料：

1. 【购车意向等级】画像分析已给出的等级（H / A / B / C / 待识别），本次判断以它为基准档位；
2. 【Notes】客户基础信息（已确认的属性事实）；
3. 【画像卡】客户群、购车决策、成交攻防、决策心理等分析结论；
4. 【跟进履历】销售顾问与客户的跟进记录。

# 判断口径

一、基准档位决定取值范围（取整数）：

| 等级 | 含义 | 成交概率范围 |
|---|---|---|
| H | 预计 7 天内可成交 | 60~100 |
| A | 预计 14 天内可成交 | 40~59 |
| B | 预计 30 天内有成交机会 | 20~39 |
| C | 预计 30 天内难以成交 | 1~19 |
| 待识别（未定级） | 信息不足，暂不判断 | 1~19 |

二、在基准档位内做微调，依据客户展现出的实际意向强度：

- 三个维度同时看：想不想买（需求是否真实明确）、能不能买（预算、付款、牌照、决策人等条件是否齐备）、多久能买（时间窗口远近与推进动作）；
- 有实质推进动作（试驾、报价、置换评估、锁单、下定、约定到店等）的，往区间上限靠；
- 时间窗口偏远（3 个月以上）、长期多店对比未锁定、多次联系未有效接通、明显防备或拖延的，往区间下限靠；
- 绝大多数普通案例落在区间中部，只有证据高度一致时才用区间两端的数值。

三、注意事项：

- 以实际行为和记录为准，客户口头表态不能单独抬高概率；
- 材料稀疏或前后矛盾时，取区间中下部，不要自行脑补；
- 跟进记录中的「意向级别」是销售顾问的主观评级，可作参考，但不能作为主要依据；
- 「待识别」客户没有有效接触或信息过少，给低位的保守值（建议 5~15）。

四、硬性约束（违反即属无效输出）：

- 成交概率必须是整数，且**严格落在基准档位对应的区间内**；
- 购车意向等级已经由画像分析确定，本次只在其区间内微调，不得越档：材料证据看起来强于档位时取区间上限，弱于档位时取区间下限；
- 输出前做一次自检：确认数值在区间内，越界则改回区间边界（强证据取上限，弱证据取下限）。

# 输出格式

只输出一个 JSON 对象，不要输出其它任何文字：

{"成交概率": <0~100 的整数>, "微调依据": "<一句话，30 字以内，说明落在区间偏高/居中/偏低的原因>"}

# 输入材料

【购车意向等级】
{level}

【Notes】
{notes}

【画像卡】
{profile_card}

【跟进履历】
{follow_up}
```

## 4. 使用方式

- 调用参数与本项目统一 LLM 层保持一致：`temperature=0.5`、`enable_thinking=false`、`max_tokens=4000`；
- 每次画像出完回传体后单次调用，无需 JSON Schema 或门禁校验；

## 5. 验证记录

- 数据：`experiments/uat_data/uat-traces-20261116-20261117`（455 根运行，批次分布 H 9 / A 41 / B 179 / C 192 / 待识别 34）；
- 抽样：分层 89 条（H 全量 9 条，其余每档 20 条），两轮独立调用（2026-11-20）；
- 结果（两轮合并取值范围）：

| 等级 | 样本数 | 成交概率范围 | 说明 |
|---|---|---|---|
| H | 9 | 62~88 | 已下定/锁单待提车的偏上（88 上下）；证据矛盾（客户否认购车、多次失联）的压在 62~68 |
| A | 20 | 45~58 | 多数居中 48~55；推进充分取 58 |
| B | 20 | 22~32 | 时间窗口远、联系不畅的偏下 22；已有试驾/看展的取 32 |
| C | 20 | 5~15 | 已购竞品、多次拒接的 5 上下；远期但仍有弱联系的 12~15 |
| 待识别 | 20 | 8~12 | 均为留资或未接通、无有效沟通，给保守值 |

- 等级间严格有序且无重叠（两轮均满足 max C < min B < min A < min H）；
- 越档情况：初版提示词两轮合计 2/178（一次 A 档输出 88、一次 B 档输出 18），加入「硬性约束」后两轮 0/178；
- 同案重复运行：平均绝对偏差 1.16 分，最大 10 分（一例 H 级 78/88，属低价顾虑类判断摇摆）。
