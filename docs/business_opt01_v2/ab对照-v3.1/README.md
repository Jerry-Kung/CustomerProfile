## 1. v3.1 改了什么

v3 立住了「来源可信、格式可靠」，但只约束了形式、没约束内容。v3.1 补四处（详见
`../../specs/business_opt01_v2-v3.1任务书.md` 与 `../v3.1-方案设计.md`）：

| 改造 | 问题 | 做法 |
|---|---|---|
| **一 · 推导链分离** | 问题 1 | `steps` 落**论证**（`reasoning_chain`），`evidence` 落**原材料**；两者不再从同一份依据分流渲染 |
| **二 · 说话人归属** | 问题 2 | `SALESPERSON_MARKERS` 值形态门 + 合并层 `subject` 以 1a 为准 |
| **三 · 锚点相关性门** | 问题 3 | 寒暄语 / JSON 残片不当证据；`value_signal` 须为锚点子串 |
| **四 · 确定性字段注入** | 问题 4 | `phone_number` 直取入参、`driver_license_status` 按「有试驾 / 有旧车」规则定 |
