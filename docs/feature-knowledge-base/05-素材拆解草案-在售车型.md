## 0. 版本结构：先纠正一处误判

此前把「同一车型出现多个价格 / 多种动力」判成素材矛盾，**这是错的**。
产品事实是：**每款车型分若干档位型号，各档配置与价格不同。**

| 车型 | 档位数 | 说明 |
|---|---|---|
| 猛士X700 | 4 | 后驱 Pro / 四驱 Max / 四驱 Max+ / 四驱 Ultra |
| 猛士M817 | 5 | Mate / Mate+ / Max / Max+ / Ultra |
| 猛士917 | 3 个常规 + 3 个特别/定制 | 增程基础 / 纯电基础 / 高地雄狮；限量创始版（增程、纯电两档）、蛟龙战甲加长定制版 |

因此 `models.json` 的结构必须把「车型」与「档位」分成两层：
一条车型条目挂一组 `configs`，动力形式、价格都允许按档位不同。规范（`04`）已按此设计。

**仍然存疑、按你的要求保持原样不动、只记遗留问题的**：
M817 的**具体档位与动力形式的对应关系**（哪几个档是插混、哪几个档是增程），
以及 715kW 与 1.5T 分别属于哪个档。材料只说了「低配插混、高配增程」这一层，
没有逐档对应。**提示词一律不改**，等业务方确认（见 `07` Q1）。
