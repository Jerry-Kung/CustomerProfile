## 一句话背景

L3 表达层当前注入的三份共享资产通篇是**广汽埃安**，而本方在售品牌是**东风猛士**。
不是知识不足，是知识有害——每跑一单都在用错品牌的产品矩阵组织画像卡。
同时全仓没有「本方品牌」的代码定义，`competing_brand` 的同品牌例外只是一句提示词。
