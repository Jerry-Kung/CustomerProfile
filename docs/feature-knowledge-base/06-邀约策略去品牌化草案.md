## 4. 落地时的注意

1. **必须核对 JSON 可解析**：`python -c "import json,io;json.load(io.open(path,encoding='utf-8'))"`。
   中文全角引号在 JSON 字符串值里是合法内容，但外层引号会被它搞乱的地方要小心。
2. **逐字比对未改字段**：S6、S7 两条应与原文逐字节相同；其余五条的
   `策略ID`／`策略类别`／`目标客户画像`／`推荐邀约动作`／`AI触发标签`／`优先级`
   六个字段也应逐字相同。这是「只改该改的」的验收方式。
3. **不要顺手改写措辞**：话术示例里「您看的这款车参数确实很亮眼」保留原句式，
   只删品牌名。审阅者要能一眼看出改动边界。
4. **这份文件是 `template-transform` 节点**，正文即输出，不经变量渲染。
   改完要跑 `test_llm_template_bindings.py`。
