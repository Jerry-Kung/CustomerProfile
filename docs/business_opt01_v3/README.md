| 文件 / 目录 | 内容 | 是否入库 |

| `审核报告-业务视角.md` | 第三方业务专家视角的检核报告（缺陷分类 + 逐案索引 + 优先动作） | **否**（含客户原话） |

报告里的每条结论都能在 `review/views/<手机号>.md` 里查到对应卡片刻与源证据。

## 为什么不入库

本目录下 `审核报告-*.md`、`review/`、`baseline-*/`、`data/`、`画像管线AB对照-*.html`
都含**未脱敏**的客户姓名、手机号与录音转写，属真实客户数据。排除规则见本目录 `.gitignore`。
仓库根 `.gitignore` 不覆盖本目录，因此必须在此单独排除。
