# 客户商机等级定级规范

## 一、规范概述

### 1.1 业务目标

建立统一、可解释、可验证的客户商机等级评定标准，指导AI客户画像分析服务基于客户数据，准确识别客户购车意向、成交条件及成交时间窗口，输出具有业务价值的商机等级。

核心目标：

1. **统一标准**：建立跨业务阶段一致的H/A/B/C等级定义。
2. **分阶段识别**：区分线索邀约阶段与转商机阶段，采用不同的证据和判断标准。
3. **识别漏跟、错判与低效投入**：通过AI评级与销售顾问评级的交叉验证，辅助优化客户经营策略。
4. **提高评级可靠性**：以真实需求、客观证据和实际行动为依据，避免主观臆测和简单关键词匹配。

### 1.2 核心评级原则

AI商机评级的本质是：

**截至当前时点，在标准跟进条件下，客户可实现的购车或成交潜力。**

评级需要综合考虑三个核心维度：

| 维度 | 定义 | 重点判断内容 |
|---|---|---|
| 想不想买 | 是否存在真实购车需求 | 购车场景、换购原因、车型兴趣、近期购车意愿 |
| 能不能买 | 是否具备成交条件 | 预算、决策人、金融方案、置换、牌照、用车条件等障碍是否可解决 |
| 多久能买 | 当前购车时间窗口 | 线索阶段看多久到店或试驾，商机阶段看多久大定或成交 |

**评级不能仅依据客户的口头意愿，还应综合分析需求明确程度、成交条件和实际行动证据。**

---

## 二、业务阶段识别规范

客户商机评级分为两个业务阶段：

- **阶段一：线索邀约阶段**，主要判断客户多久能够到店或试驾。
- **阶段二：转商机阶段**，主要判断客户多久能够大定或成交。

### 2.1 阶段识别规则

根据客户画像分析服务收到的后台输入数据包，判断客户所属阶段。

| 阶段 | 识别条件 | 评级关注重点 |
|---|---|---|
| 线索邀约阶段 | 输入数据包中不包含试驾或试驾录音相关数据 | 真实购车需求、购车时间窗口、到店/试驾意愿 |
| 转商机阶段 | 输入数据包中包含试驾或试驾录音相关数据 | 大定时间、交易动作、成交障碍 |

### 2.2 阶段判定优先级

**以后台输入数据包中的试驾相关数据作为阶段划分的决定性依据。**

1. 输入数据包包含试驾数据或试驾录音数据时，直接认定客户已进入**转商机阶段**。
2. 输入数据包不包含上述数据时，认定客户处于**线索邀约阶段**。
3. 不要求试驾数据和试驾录音同时存在，任意一类存在即可认定为转商机阶段。
4. 阶段判断优先于商机等级判断，先确定阶段，再执行该阶段对应的评级标准。

该规则为后台服务的统一阶段判定口径，不得仅因客户口头表示准备到店、准备试驾或准备购买，就自动切换至转商机阶段。

## 三、统一商机等级定义

无论客户处于哪个业务阶段，均使用统一的H/A/B/C等级体系。

| AI等级 | 统一定义 | 核心判断 |
|---|---|---|
| **H级** | 预计7天内具备成交条件 | 真实需求明确，车型基本确定，购买条件基本具备，已出现实质交易推进信号 |
| **A级** | 预计14天内具备成交条件 | 近期购车需求明确，车型/预算基本匹配，愿意采取具体购车行动，障碍较少且可解决 |
| **B级** | 预计30天内有成交机会 | 有真实购车需求，但购车时间、车型、价格或决策条件至少一项尚不明确，需要继续推进 |
| **C级** | 预计30天内难以成交 | 远期购车、需求弱、仅体验/咨询，或存在短期无法解决的关键障碍 |
| **待识别** | 信息不足，暂不判断 | 未有有效接触，沟通信息过少，暂不作高低意向判断 |

### 3.1 等级解释

**H级：高确定性、短期成交机会**

客户已具备较明确的真实购车需求和成交条件，近期能够完成交易推进，且具有可验证的实际行动证据。

**A级：明确意向、近期推进机会**

客户购车意向明确，主要成交条件基本具备，预计短期内能够进一步推进，但尚未达到H级所要求的成交确定性。

**B级：存在需求、需要持续培育**

客户存在真实购车需求，但在购车时间、车型选择、预算或决策条件方面仍有不确定性，需要通过持续沟通推动成交。

**C级：短期低成交机会**

客户近期购车可能性较低，或存在明显的需求不足、时间不匹配、成交障碍等问题。

**待识别：证据不足**

现有信息不足以支持有效商机判断，不应强行归入H/A/B/C等级。

特别注意：

**待识别 ≠ C级。**

信息不足与低购车意向属于不同概念，不能因为缺少证据就认定客户没有购买意向。

## 四、阶段一：线索邀约阶段评级标准

### 4.1 阶段定位

本阶段的核心任务是判断客户是否存在真实购车需求，以及预计多久能够到店或试驾。

重点关注：

- 真实购车需求
- 购车时间窗口
- 到店或试驾意愿

### 4.2 分级判定标准

#### A级：高意向邀约线索

满足以下主要特征：

1. 有真实购车需求，预计14天内购车。
2. 车型、预算基本匹配。
3. 明确愿意在7天内到店或试驾，或已接受具体邀约时间。
4. 无明显硬性障碍。

**业务含义：** 客户具有明确的近期购车意向，且有较高可能性在短期内到店或试驾，应优先安排销售跟进。

#### B级：中等意向邀约线索

满足以下主要特征：

1. 有购车需求，预计30天内可能购车。
2. 愿意了解、试驾或到店，但时间不确定，或预计8—14天后到店。
3. 存在部分待确认事项。

**业务含义：** 客户具有真实购车需求，但尚未形成明确、紧迫的到店或试驾计划，需要进一步沟通和邀约。

#### C级：低意向邀约线索

满足以下一项或多项特征：

1. 30天以上才考虑购车，近期不买。
2. 无明显购车需求。
3. 明确不愿到店或试驾。
4. 仅询价、体验或活动咨询。
5. 存在短期不可解决的障碍。

**业务含义：** 客户短期转化机会较低，应根据实际情况降低跟进优先级或转入长期培育。

#### 待识别：信息不足

满足以下特征：

- 未有有效接触。
- 现有信息不足以判断购车意向。

应继续补充客户信息，不作高低意向判断。

### 4.3 线索阶段评级上限

**规则1：线索邀约阶段最高只能评为A级，不能评为H级。**

即使客户表现出极强的购车意向，只要尚处于线索邀约阶段，其商机等级最高为A级。

线索阶段允许的评级结果：

`A级 / B级 / C级 / 待识别`

## 五、阶段二：转商机阶段评级标准

### 5.1 阶段定位

本阶段客户已进入试驾相关业务环节，核心任务由到店邀约转变为促进大定或成交。

重点关注：

- 大定时间
- 实际交易动作
- 关键成交障碍

### 5.2 分级判定标准

#### H级：高确定性成交商机

满足以下主要特征：

1. 预计7天内成交。
2. 车型、版本基本确定。
3. 预算和付款方式具备。
4. 已进入报价、权益、金融、置换、库存、交付、订单等实质交易环节的讨论。

**业务含义：** 客户已经进入实质性成交推进过程，交易条件基本成熟，具有较高的近期成交潜力。

#### A级：明确意向成交商机

满足以下主要特征：

1. 预计14天内成交。
2. 试驾反馈正向。
3. 愿意进行报价、二次到店、带家人体会、评估置换、讨论金融等下一步动作。
4. 剩余障碍1—2项且可解决。

**业务含义：** 客户已形成较明确的购买意向，愿意采取具体成交推进动作，但仍存在少量待解决问题。

#### B级：需要持续推进的成交商机

满足以下主要特征：

1. 预计30天内有机会成交。
2. 存在真实需求，但车型、价格、竞品、家庭意见或购买时间仍不确定。
3. 下一步动作模糊。

**业务含义：** 客户存在成交可能性，但尚未形成清晰的交易路径，需要进一步确认需求、处理异议和推进决策。

#### C级：短期低成交机会商机

满足以下一项或多项特征：

1. 30天内成交可能性低。
2. 体验型试驾。
3. 明确暂不购车。
4. 存在预算、家庭、竞品等短期难以解决的问题。

**业务含义：** 客户虽然已经进入试驾相关业务阶段，但当前不具备明确的短期成交条件。

### 5.3 转商机阶段评级范围

转商机阶段允许的评级结果：

`H级 / A级 / B级 / C级 / 待识别`

对于已进入转商机阶段但有效证据不足的客户，仍应保留待识别结果，避免无依据定级。

## 六、跨阶段统一判定规则

### 6.1 H/A级必须同时具备多维证据

**规则2：H级和A级必须同时具备时间、需求证据和实际行动证据。**

具体包括：

1. **时间证据**：具有明确的近期购车或成交时间窗口。
2. **需求证据**：具有真实且相对明确的购车需求。
3. **行动证据**：已经采取或明确接受能够推进购车的具体行动。

三个维度应综合判断，不能仅凭某一个维度将客户评为H级或A级。

例如：

- 客户口头表示“最近就买”，但车型、预算、实际行动均不明确，不足以直接认定为H/A级。
- 客户表达强烈兴趣，但没有明确购买时间和下一步行动，不足以直接认定为H/A级。
- 客户已经讨论具体报价、金融方案及订单，但仍需结合购买时间和关键障碍判断最终等级。

### 6.2 关键障碍处理

影响购车或成交的关键障碍包括但不限于：

- 预算或付款能力不匹配。
- 家庭成员或其他决策人尚未达成一致。
- 金融方案尚未落实。
- 置换条件尚未确认。
- 牌照、用车条件等客观限制。
- 车型、版本、库存或交付条件不满足。
- 竞品对比尚未形成结论。

应重点判断障碍是否能够在目标成交时间窗口内解决，而非仅根据障碍数量判断等级。

### 6.3 客观证据优先

评级应优先参考能够证明客户真实行动和交易推进程度的客观证据。

例如：

- 明确接受具体到店或试驾安排。
- 已完成试驾并提供反馈。
- 主动要求报价或金融方案。
- 讨论置换评估。
- 讨论车型版本、库存或交付。
- 讨论订单或支付安排。

上述证据需要结合业务阶段、上下文和时间窗口综合判断，不得机械地以关键词出现与否直接决定等级。

## 七、AI商机等级判定流程

后台服务按照以下六个步骤进行评级。

### 步骤1：检查有效客户信息

判断是否已获得足以支持评级的有效客户信息。

- 信息充分：继续评级。
- 信息不足：输出待识别。

### 步骤2：判断真实购车需求

判断客户是否存在真实购车需求。

- 存在真实需求：继续分析。
- 需求弱、仅体验或咨询：结合证据评为C级。
- 证据不足以判断：输出待识别。

### 步骤3：识别业务阶段

根据后台输入数据包判断当前阶段：

- 不包含试驾相关数据：线索邀约阶段。
- 包含试驾或试驾录音相关数据：转商机阶段。

随后选择对应阶段的评级标准。

### 步骤4：判断时间窗口

不同阶段采用不同的时间窗口判断：

**线索邀约阶段：**

- 预计多久到店或试驾。
- 近期购车时间窗口是否明确。

**转商机阶段：**

- 预计多久能够大定或成交。
- 近期成交条件是否成熟。

### 步骤5：判断实际行动证据

判断客户是否存在能够支持H/A级的实际行动证据。

若缺少必要的行动证据，不应仅根据口头意愿认定高等级。

### 步骤6：识别关键障碍

判断是否存在短期不可解决的关键障碍。

- 存在明显且短期无法解决的关键障碍：应降低等级。
- 不存在明显硬性障碍：结合其他证据确定最终等级。

### 7.1 标准输出内容

AI评级结果应包含以下内容：

| 输出项 | 说明 |
|---|---|
| AI商机等级 | H/A/B/C/待识别 |
| 判断依据 | 支撑等级判定的核心客户事实与证据 |
| 关键障碍 | 当前影响客户到店、试驾或成交的主要问题 |
| 下一步建议 | 对销售顾问后续跟进的建议 |
| 评级置信度 | AI对当前评级结果的可信程度 |

其中，判断依据应尽量能够追溯至实际输入数据，不应使用缺乏证据的主观判断代替客户事实。

## 八、AI评级与销售顾问评级的交叉验证

AI评级不仅用于识别客户商机，还用于与销售顾问的人工评级进行交叉验证，发现漏跟、错判与资源投入不合理的问题。

### 8.1 四象限分析

根据AI评级和顾问评级，将客户划分为四个经营区域。

| | 顾问评级高（H/A） | 顾问评级低（B/C） |
|---|---|---|
| **AI评级高（H/A）** | 高效推进区 | 重点挽回/跟进区 |
| **AI评级低（B/C）** | 虚假繁荣/耗时区 | 常规沉淀区 |

### 8.2 四类经营区域说明

#### 1. 高效推进区

**AI评级高，顾问评级高。**

- 双向确认高潜客户。
- 应重点关注转化周期、报价谈判与大定推进。

管理目标：提高高潜客户成交效率。

#### 2. 重点挽回/跟进区

**AI评级高，顾问评级低。**

- AI高潜但顾问定低。
- 应重点复盘遗漏话术、联络、耐心不足，以及防止高潜客户流失。

管理目标：识别被低估的高潜商机，减少漏跟和错判。

#### 3. 虚假繁荣/耗时区

**AI评级低，顾问评级高。**

- AI有疑似低意向理由。
- 警惕被客户套取方案或被虚报影响。
- 避免无效消耗。

管理目标：识别可能被高估的商机，减少低效跟进投入。

#### 4. 常规沉淀区

**AI评级低，顾问评级低。**

- 双向确认低意向。
- 转入自动化培育池。
- 降低人工投入。

管理目标：合理配置销售资源，维持长期培育。

### 8.3 管理动作优先级

**优先处理错位象限（右上、左下），再优化高效推进区转化。**

重点关注AI与顾问判断不一致的客户，分析产生差异的原因，并据此优化销售跟进与商机识别策略。

## 九、上线校准与效果验证原则

### 9.1 不按固定比例分配等级

商机等级应根据客户真实情况和业务证据确定。

**禁止按照预设比例强行分布H/A/B/C等级。**

不同客户群体、不同渠道及不同业务时期，商机等级分布可以存在差异。

### 9.2 以实际成交率验证等级有效性

上线后重点验证各等级客户的真实成交率。

预期等级区分关系：

**H级成交率 > A级成交率 > B级成交率 > C级成交率**

该关系属于评级体系的效果验证目标，不应通过人为控制评级比例实现。

### 9.3 AI评级作为交叉验证工具

AI评级应作为销售顾问评级的校验与纠偏工具，而非无条件替代人工判断。

当AI评级与顾问评级存在差异时，应结合客户证据和实际转化结果进行复核，并持续优化评级标准。

| 编号 | 约束内容 |
|---|---|
| R01 | AI评级统一采用H/A/B/C/待识别五种结果 |
| R02 | 商机等级以当前可实现的购车/成交潜力为核心判断对象 |
| R03 | 根据后台输入数据包是否包含试驾或试驾录音相关数据确定业务阶段 |
| R04 | 线索邀约阶段最高只能评为A级，不允许H级 |
| R05 | H级和A级必须同时具备时间、需求证据和实际行动证据 |
| R06 | 线索邀约阶段重点判断真实需求、购车窗口和到店/试驾意愿 |
| R07 | 转商机阶段重点判断大定时间、交易动作和关键成交障碍 |
| R08 | 客户信息不足时输出待识别，不得直接等同于C级 |
| R09 | 对存在短期不可解决关键障碍的客户，应降低评级 |
| R10 | 不得按照固定比例强行分配等级 |
| R11 | 应通过实际成交率检验等级区分度 |
| R12 | AI评级与顾问评级交叉验证，重点发现漏跟、错判和低效投入 |
| R13 | 输出结果应包含评级、判断依据、关键障碍、下一步建议及评级置信度 |
