# 在 assemble_l3 函数内，写入 result1 之前：
# 拍扁 resistances 数组成一条文本，写进 notes
resistances_items = analysis_result.get("resistances", [])
if resistances_items and isinstance(resistances_items, list):
    # 格式：「抗性1/抗性2/抗性3」
    names = [r.get("resistance_name", "") for r in resistances_items if isinstance(r, dict)]
    names = [n for n in names if n]
    if names:
        resistances_text = "/".join(names)
        notes.append({
            "attribute_key": "resistances",
            "attribute_value": resistances_text,
            "reasoning_detail": {
                "summary": "由客户抗性分析汇总而来",
                "steps": [f"客户抗性分析得出 {len(names)} 项顾虑", "汇总为文本：" + resistances_text],
                "evidence": [f"{r.get('resistance_name')}: {r.get('description', '')[:60]}" for r in resistances_items[:3]],
                "confidence": 0.75
            }
        })
```

## 4. 问题3修复：persona 输出格式稳定（P1）

**文件**：`src/customer_profile/templates/customer_profile_pipeline__pipeline_l1_persona.txt`

**补充内容**：

```markdown
## 输出格式补充

`persona` 中的每一项**必须给 `value` 键**，即使值为空字符串。下游依赖固定的 key 结构。

**必填项**（即使为空也要给出该项）：

- `gender`、`age_range`、`occupation`、`income_level`、`family`
- 其余字段（`education`、`purchase_power`、`personality` 等）若信息不足，可省略或给空 `value`。

**错误示范**（会导致下游读不到字段）：

```json
{
  "persona": {
    "gender": {"value": "男", "provenance": [...]},
    // ❌ 缺了 age_range 项，下游会读到 undefined
    "occupation": {"value": "司机", "provenance": [...]}
  }
}
```

**正确示范**：

```json
{
  "persona": {
    "gender": {"value": "男", "provenance": [...]},
    "age_range": {"value": "", "provenance": []},  // ✓ 给了空值
    "occupation": {"value": "司机", "provenance": [...]}
  }
}
```
```
