# 模板资源

提示词与模板正文（68 份），逐字符外置为受 Git 管理的资源文件。

- 命名：`<workflow_slug>__<node_id>.txt`。slug 是模块与模板共用的稳定标识，见各工作流模块。
- **唯一运行期来源就是本目录**，由 `TemplateRepository` 按名字加载，缺文件即报错。
- **正文默认不可改**。任何提示词文本改动都属业务优化，须单独提出并获得确认。
- 文本里保留 `{{#node_id.field#}}` 引用与 `{{ "字面量" }}` 形态原样；由
  `templates.render_text` 在渲染时把引用映射成本节点的入参名，见该函数的说明。
- 正文是**运行期事实来源**，不存在第二份副本。改动正文即改运行行为，因此改动需要评审。
- **哪些资产该进知识库**：只有「随合作方变」或「讲业务知识」的内容才迁到
  `knowledge/`。标签库、证据格式、画像格式这三份**留在本目录**——它们逐字未改、
  与图结构绑定、且不随合作方变化；迁过去的收益小于 `definition_hash` 漂移的代价。
  邀约策略已迁出（去品牌化后跨合作方成立，见 `knowledge/common/`），这是分界的样本。
- **提示词驱动的产出若面向销售（Notes 的 `reasoning_detail`、画像卡 section），正文里要写清可读性要求**：证据锚点须指向客户原始数据中的一段内容，推理步骤须是真人看得懂的推导链，不得输出内部审计/规则用语或占位串。见 `docs/business_opt01_v2/v2.1-整改设计.md` §1。
