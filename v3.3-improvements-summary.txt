# v3.3 可靠性改进 - 完成总结

## 改进已完成

针对 docs/runbooks/跑批可靠性.md 分析的6个可工程化解决问题，
本轮完成了**4项高优先级改进**。

### 已完成（高优先级）

1. **A4 - anomaly落库**
   - request_attempts 增加 anomaly、finish_reason 列
   - 异常原因不再永久丢失，可事后诊断

2. **A3 - LLM输出量下限闸门**
   - 检测 finish_reason 异常（length/content_filter等）
   - 可选的输出token下限检测
   - 防止输出塌陷22倍却静默通过

3. **A2 - 失败案自动重跑**
   - --retry-failed N 参数，最多自动重跑N轮
   - 每轮退避60秒
   - 消除v3.2的4/8案瞬断损失

4. **A5 - 参数错配防护**
   - 批次ID以A-开头时检查workflow_id
   - 转写缓存目录为空时提示
   - 防止臂选错(62MB)和缓存落空(11段录音)

### 待后续（中低优先级）

- **A1 - 单渠道失败语义**：需回归BLOCKED/SKIPPED口径
- **A6 - 通用产出闸门**：需逐层梳理断言
